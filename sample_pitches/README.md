# Sample pitches

Ready-to-use startup pitches for testing the panel — paste them into the Streamlit box,
or run directly from the CLI:

```bash
python run.py sample_pitches/fleetshift.txt
```

| File | What it tests |
|------|---------------|
| `fleetshift.txt` | A **strong**, numbers-heavy pitch — watch the sharks fight over valuation |
| `vibeverse.txt`  | **Hype, no traction** — watch Nikhil & Sameer pass |
| `gharsolar.txt`  | **Great story, ugly margins** — genuine disagreement |

(The default `../sample_pitch.txt` is TiffinAI.)
